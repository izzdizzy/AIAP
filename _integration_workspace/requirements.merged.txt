## Installation Notes

### Backend
```bash
pip install -r requirements.merged.txt
```

### Frontend
```bash
cd frontend
npm install
```

## Feature Flags
Set in .env file:
- ENABLE_CAD=true/false
- ENABLE_DIABETES=true/false
- GEMINI_KEY=<api_key_for_cad>
- DIABETES_GEMINI_KEY=<api_key_for_diabetes> (optional, can use same as GEMINI_KEY)
